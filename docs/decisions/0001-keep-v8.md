# 0001 — Keep V8; JavaScriptCore is a post-1.0 experiment

**Status:** accepted
**Date:** 2026-09-07

## Context

Cobalt's earliest plan made replacing V8 with JavaScriptCore the guiding principle of
the project, scheduled at 0.3.0 — before the Blink renderer was even brought up. That
ordering made the riskiest, least valuable piece of work a blocker for the piece of
work that actually produces a browser.

## Decision

V8 stays. It is the engine Cobalt ships, indefinitely.

A JavaScriptCore backend is retained as Stage 12: post-1.0, on `experiment/jsc`,
behind a build flag that defaults to off, and abandonable at any point.

## Why

- Chromium is built around V8. Blink's bindings, the garbage collector's interaction
  with the DOM, snapshotting, and the debugging protocol all assume it. Replacing it
  is not a swap at an interface; it is a rewrite of the binding layer.
- The user-visible gain is close to zero. Nobody installs a browser for its JS engine.
  Kiwi's value is extension support and being a maintained Chromium on Android.
- The cost is unbounded. Every Chromium rebase (Stage 5, quarterly) would have to
  carry the binding-layer divergence forward.
- The work is not urgent. If JSC turns out to be worth it, it is just as possible
  after 1.0 as before, on a shipped and stable base.

## Consequences

- The `JsEngine` / `JsContext` / `JsValue` interface in `:modules:core` stays free of
  engine-specific concepts. That is the only cost we carry forward, and it is a cost
  we would pay anyway for testability.
- `JsEngine.isJsc` was removed. A flag naming one specific candidate backend is
  exactly the leak this interface exists to prevent; backends identify themselves
  through `name`.
- Stage 2 still documents Kiwi's V8 integration points. Documentation is cheap and
  gives Stage 12 a map if it ever runs.

## Rejected alternatives

**Swap the engine first, as originally planned.** Rejected: it puts the highest-risk
work before there is anything to run it in, and it delays every user-visible feature
behind an internal detail.

**Drop JSC from the plan entirely.** Rejected: the engine-neutral interface costs
nothing to keep, and a documented experiment with entry conditions is more useful than
an idea that keeps resurfacing without one.
