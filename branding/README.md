# Branding

One SVG is the source. Every raster is generated by `tools/make-icons.py`, so
the six Android densities cannot drift out of sync — which is what happens when
someone updates the 192px icon and forgets mdpi.

```sh
tools/make-icons.py branding/cobalt-icon.svg           # regenerate
tools/make-icons.py branding/cobalt-icon.svg --check   # fail if stale
tools/recolour-icon.py branding/kiwi_logo_circle.svg \
    branding/cobalt-icon.svg --palette electric        # re-derive from source
```

Needs `librsvg2-bin` (the source uses gradients, masks and filters that pure
Python SVG renderers get wrong) and Pillow for assembling the `.ico`.

## Provenance — read before changing the mark

`cobalt-icon.svg` is **derived from Kiwi Browser's `kiwi_logo_circle.svg`**,
Copyright (c) 2022 Geometry OU (Kiwi Browser), BSD 3-Clause. The licence text is
in `LICENSES/kiwi-browser-BSD-3-Clause.txt` and the attribution is embedded in
the SVG header.

BSD-3 permits modifying and redistributing the artwork provided the copyright
notice is retained. Clause 3 restricts using **the names** "Kiwi Browser" and
"Geometry OU" to endorse or promote Cobalt — not the artwork itself. So the
recolour is permitted under copyright.

**Two things the licence does not settle**, recorded so the decision stays made
knowingly rather than inherited by whoever touches this next:

1. **Trademark is separate from copyright.** A BSD grant conveys no trademark
   rights, and a logo generally functions as a mark. App stores act on
   impersonation complaints on their own terms, regardless of file licences.
2. **A recolour alone does not make a mark distinct.** Anyone who knows Kiwi
   would still read a recoloured Kiwi logo as Kiwi.

## Why the mark is inverted

The source is a **white bird on a coloured gradient disc**. Cobalt is a **blue
bird on a plain dark ground** — the figure and ground swap roles.

That is deliberate and it is what resolves the point above. The silhouette
carries the lineage, so the relationship to Kiwi is legible and honestly
acknowledged; the inversion carries the separation, so nobody mistakes Cobalt
for Kiwi or for something Kiwi ships. Inspired by, not descended from, and not
pretending otherwise.

`variant-inverted-light.svg` is the same inversion on a pale ground, kept
because it holds up better at 48 px against a busy launcher wallpaper.

## Palette note

Every colour in these SVGs must be **6-digit hex**. SVG 1.1 does not understand
8-digit `#RRGGBBAA`, and an earlier palette here used one: it parsed wrong while
still rendering plausibly, which is the worst way for a colour bug to fail.
Opacity belongs in the `stop-opacity` attribute the source already carries.
